## What the numbers mean

- **steps**: optimizer steps the step-time model predicts in the charged time (time_target − 3 s save reserve), with a per-run chip-jitter draw (default sd 0.4%). 1% of steps ≈ 0.00057 bpb.
- **bpb_2m**: predicted public-shard rehearsal bpb (trained weights, first 2M tokens); sd includes seed luck (≈0.0006) unless a training seed was given.
- **official**: bpb_2m + the rehearsal→official offset (+0.0066 ± 0.0004). p10/p50/p90 are Monte Carlo percentiles.
- **P(beat best)**: fraction of draws with official < the best official score.
- **Δ vs base / P(< base)**: paired with the base under common random numbers, so shared noise cancels.
- **support**: `ok` = every changed knob value was seen (or lies between seen values) in the fitted runs; `EXTRAP` = the surrogate is guessing.
